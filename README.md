# Machine Learning Practice Projects

This repository contains a collection of small Machine Learning projects created to strengthen my practical understanding of Machine Learning concepts.

The main purpose of these projects is to understand how Machine Learning models learn from different types of data, make predictions, and perform under different data conditions.

These projects were built as hands-on practice after studying and implementing individual Machine Learning algorithms.

---

## 🎯 Purpose

The projects in this repository focus on understanding the complete basic Machine Learning workflow:

- Understanding the problem
- Loading and exploring datasets
- Data preprocessing
- Feature selection
- Splitting data into training and testing sets
- Training Machine Learning models
- Making predictions
- Evaluating model performance
- Understanding how different datasets affect model performance
- Comparing model behavior across different problems

## 🧠 What I Practiced

Across these projects, I practiced different parts of the Machine Learning workflow.

### 1. Data Loading

Used different sources of datasets, including:

- Datasets directly available through Scikit-learn
- CSV datasets
- Other structured datasets used for practice

### 2. Data Understanding

- Checking dataset shape
- Understanding features and target
- Checking data types
- Identifying missing values
- Understanding distributions
- Exploring relationships between variables

### 3. Data Preprocessing

Depending on the project, preprocessing included:

- Handling missing values
- Encoding categorical variables
- Feature scaling
- Feature selection
- Train-test splitting
- Preparing data for Machine Learning models

### 4. Model Training

Applied suitable Machine Learning algorithms based on the problem, including classification and regression models.

### 5. Prediction

Used trained models to make predictions on unseen/test data.

### 6. Model Evaluation

Evaluated models using appropriate performance metrics.

#### Classification

- Accuracy
- Precision
- Recall
- F1 Score
- Confusion Matrix

#### Regression

- MAE
- MSE
- RMSE
- R² Score

---

## 🔍 Learning Focus

A major purpose of these projects was to understand that Machine Learning performance depends not only on the algorithm but also on the data.

I practiced observing how model performance can change depending on:

- Dataset size
- Feature quality
- Data distribution
- Missing values
- Feature scaling
- Relevant and irrelevant features
- Training/testing split
- Type of Machine Learning problem

This helped me understand the practical relationship between:

**Data → Preprocessing → Model → Prediction → Evaluation**
